# 真实消费链

按风险检查实际经过的节点：定义/配置真源 → 生成/注册/加载 → 暴露/寻址 → 授权对象 → 执行对象 → 运行时消费/副作用 → 状态生命周期 → 异步失败 → 持久化/重启恢复 → 发布/回滚。

- 配置须到真实读取及行为生效；接口须到实际暴露和执行，内部方法可调用不等于客户端可达。
- 授权对象与执行对象须绑定同一身份，或在执行前重验，不能仅凭权限函数返回 true。
- 旧异步回包须通过版本/请求标识等拒绝，或证明不会覆盖新状态。
- 实际涉及的 missing/closing/expire/timeout 须明确副作用、回包和状态收敛，避免永久 pending、重复结算；覆盖并发、幂等、补偿与恢复。
- 同一时间事实使用兼容时钟，运行时与重启恢复语义一致。
- 当前功能需要回滚时，验证开关、降级、数据兼容或执行步骤；口头“可回滚”不算证据。

选择能覆盖本次风险的单元、集成、回归、启动/升级、并发、故障或性能验证；在 `06` 记录命令/场景、结果和限制。
