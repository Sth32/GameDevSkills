# 分步与接力

- 每个 Step 是可独立理解、实现、验证与 review 的纵向行为闭环，步骤表留在同一 `06`；跨单元依赖只记在 `00`。
- 每步补齐规则、配置/数据、失败与副作用边界，清理危险占位并验证；在约定 review 点交接。已有连续执行授权不重复确认，范围/风险/假设实质变化时再沟通。
- 编码前、review 边界及暂停/结束前，`06` 必须能独立回答：工作单元、模式与步骤状态、确认范围、实际代码基线/入口、已完成行为及证据、有效偏差/阻塞、下一动作和进入条件；只引用上游，不复制全文。
- 恢复时先核对接力点与实际代码/diff，不一致则据代码事实修正文档并告知用户，再决定继续或重做 review，不依赖旧聊天。
- 全部步骤完成后用实际实现替换计划、清除失效风险，接力点改为等待本单元正式交叉 Review；保留真实延期项及未覆盖验证。
