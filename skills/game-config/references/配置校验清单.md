# 配置校验

按变化选最小充分检查，优先项目现有校验器；导表成功不等于加载或引用有效。

| 变化 | 检查 |
|---|---|
| 数据 | 解析、类型/空值、联合键唯一、单位/范围/枚举/概率、集合对齐 |
| 引用/资源 | 跨表/父子引用、资源路径与 ID 域；删除/重命名后无悬空引用 |
| Schema | 默认值/兼容、索引/引用、目标端类型同步；旧配置可加载或有迁移 |
| 生成/输出 | 标准命令结果、目标 diff、字段可见性、真实消费端加载 |
| 策划收尾 | 合法域与字段约束成立；当前默认/占位不破坏加载、引用或实现测试，否则仍阻塞 |

结果回写对应事项，日志仅链接；尚缺代码接线标入后续依赖，不宣称功能生效。
