# 配置源识别

追踪维护者、加载方式和生成关系，按职责分类；不能由扩展名判定。

| 类别 | 证据与动作 |
|---|---|
| 真源 | 由通用加载器消费的声明式数据；含纯数据 Lua 等，授权后可改 |
| 生成物 | 会被导表/生成覆盖的数据包、类型或访问代码；改真源后再生 |
| 声明式 Schema | 字段、类型、索引、引用、输出范围、校验声明；单独确认 |
| 程序逻辑 | Component/Manager/Handler、`VIEW_MAP`、运行时注册、状态机、同步及生成器/加载器/模板逻辑；留给实现阶段 |

XML 可是真源、生成物或嵌入可执行规则，静态映射也可能参与运行时行为；查清后再写，仍不明则标记“类别待确认”。
