# 复杂配置管线

- 按逻辑对象连起真实源、Schema、生成物、输出目标和消费端，只记录实际存在的环节。多源需明确主键、引用、重复事实、覆盖优先级及各源执行方式。
- 新表/异构结构按行粒度、维护者和已有工具选源，不机械塞入 Excel。新源或 Schema 单独确认；生成/加载程序变更留给实现阶段。
- 改值通常只生成数据；新增字段/类型检查是否还需生成访问代码，输出范围变化检查受影响目标。生成 diff 应匹配变化，只改值却产生大片代码 diff 时先调查。
- 多端检查类型/数据一致和字段输出范围，服务端专属字段不得出现在客户端。
- 生成器确定且成本可接受时，无输入变化再生成一次，应无新 diff；否则记录不稳定，不手改输出掩盖。
