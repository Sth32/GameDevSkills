# 合同检查

- 属性/属性组：实体标识、字段类型/单位/枚举/缺省或空值、权威者与实际同步载体、全量/增量/按需/广播、首次获得、变化触发、可见范围、清除和重同步。
- 生命周期：核对实际涉及的登录/重连、创建/进入视野、销毁/离开视野、权限或关系变化、跨场景。实体存在不等于客户端仍可见；写回所属属性或接口，不另列重复表。
- RPC/事件：方向、发送/接收者、触发时机、参数与限制、同步受理和最终结果、异步关联 ID、两处错误语义；只记录客户端确需处理的重复/超时/顺序，复杂结构用最小示例。
- 表现充分性：状态、时间基准、进度、资源 ID 是否由服务端或明确配置合同提供；不足时说明影响和上游补齐位置，不靠客户端猜测或硬编码。

省略客户端 UI/MVC、缓存与资源加载设计、无关服务端线程/持久化细节、完整调用栈及 Schema。共享合同只引用，当前文档仅保留本单元新增/变化与必要依赖。
