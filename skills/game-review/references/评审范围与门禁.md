# 评审范围与门禁

| 范围 | 必须读取的材料 | 默认前置 |
|---|---|---|
| 单线 | 01–06、实际客户端合同、代码/配置 diff、生成物与运行/测试证据 | 01 整理完成；02、03 已收敛；04 已完成；05 骨架已完成；06 已完成；客户端合同可移交 |
| Uxx | 00 指向的共享基线、自身/祖先需求、实际 02–06、直接依赖合同、当前代码/配置及客户端证据 | 本单元实际阶段链达到上述终态，前驱达到本单元所需稳定状态；父文档“已拆分”不是叶单元未完成 |
| 整体 | 全部目标分支 Review、客户端合同、共享需求与当前组合代码/配置证据 | 目标叶单元分别 Review 完成，并存在集成风险 |

`00` 只记录稳定 ID、范围、依赖、当前阶段/文档和整体 Review 指针，不复制阶段状态或业务正文；推进依据仍读实际文档。

缺口需指出具体文档与状态，按入口的人工协作约定推进，不静默补写上游通过。

集成风险包括共享代码/数据、状态机、配置、协议命名空间、客户端合同或迁移/发布顺序。复用仍有效的分支结论，检查需求覆盖、共享事实冲突、接口缺口、依赖时序和评审后漂移。

## 评审中拆分

仅当范围确有独立生命周期时暂停受影响 Review，回到最早合适阶段更新 `00`，分配新稳定 Uxx；ID 不编码依赖、不复用。专属事实移入子文档，共享事实引用，父文档标记 `已拆分` 并停止直接推进。新叶单元分别 Review，原报告只保留有效共享结论；整体报告只复核受影响集成项，无关兄弟保持原状态。
