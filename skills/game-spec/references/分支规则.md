# 分支规则

- Uxx 表示可独立确认、推进、阻塞或 Review 的范围；不因需求大或预期并行机械拆分。
- 给后继分配新稳定 Uxx，拓扑只写依赖；先更新 `00-工作流索引.md` 的单元、范围、依赖、当前阶段/文档和整体 Review 指针，再将专属事实移入同目录的 `Uxx-01-<主题>-原始需求.md`；分支号与阶段号至少两位补零。
- 共享事实只留在父文档，叶文档引用而不复制；没有共享事实不补建共享 `01`。已拆分父文档标记 `已拆分`，由叶单元继续；该状态不代表需求完成。
- 核对本单元真实依赖的状态与证据；叶文档 `整理完成` 后可进入 `02`，不等待无依赖兄弟分支。有缺口按入口的人工协作规则处理。

`00` 只存路由，不复制业务事实或阶段状态；仅路由变化时更新。
