# 文档位置

1. 使用目标项目根目录，不使用技能安装目录或任意当前目录；目标不明时澄清。
2. 先按已有文档、引用或 `00` 查找同功能目录并续写；跨天或配置变化不另建。候选权威目录不唯一时澄清，明确要求迁移才移动并更新引用。
3. 新建根目录按“本次指定 → 项目根目录 `.game-dev-workbench.json` 的 `documentRoot` → `Workbench`”选择。文件或字段缺失用默认值；字段须为非空相对路径字符串，需读取的配置无效时说明并停止依赖它的新建写入，不静默回退。
4. 新建功能目录为 `<文档根目录>/<YYMMDD><功能名>/`，日期取首次建档的用户当地日期，不增加分类或分支子目录。指定功能路径或带日期目录名时原样使用，不重复拼接日期和功能名。
5. 配置仅在执行技能时按需读取，不自动创建或改写；不读环境变量、个人配置，不写入 AGENTS.md。

单线文件为 `01-原始需求.md`；分支命名见 [分支规则](分支规则.md)。已有文件按实际引用续写，不因旧命名创建副本；明确要求统一旧名时才原位重命名并更新引用。
