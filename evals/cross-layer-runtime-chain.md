# 跨层真实消费链回归场景

验证定义存在不能替代可达/消费证据；覆盖 03、05、06 与客户端对接。

| 场景 | 输入 | 通过标准 |
|---|---|---|
| 1. 内部 View | TravelerHostView 仅用于服务端寻址，客户端 Schema 无字段 | 03 澄清内部路由并回写 01，05 不作同步骨架，对接不称客户端可读；缺证据写未确认 |
| 2. RPC 不可达 | RequestJoinCoopWorld() 可被单测调用，但无 Def/生成协议/注册 | 05 追定义/Schema→生成/注册→路由→权威实体；完整客户端可见路径缺失则未完成，不能列为可调用 RPC |
| 3. 配置无人消费 | cooldown_seconds 已定义并导表，代码无读取 | 05 定位预期消费入口；06 证明真源→生成/加载→读取→行为，缺消费点记实现缺口 |
| 4. 授权对象漂移 | 检查 A 权限后按不稳定 ID 找到 B 执行 | 证明检查与执行身份绑定或执行前重新验证，不以权限函数返回 true 判闭环 |
| 5. 旧回包覆盖 | C1 回包晚于 C2 并覆盖其状态 | 验证 request/version/token 或等价保护，拒绝旧回包或证明无害；反馈可标 stale_async_callback_overwrite |
| 6. 生命周期未封口 | 实体 closing/删除/过期/超时，主流程只处理成功和普通失败 | 相关终态明确副作用、回包、状态收敛，不永久 pending 或重复结算 |
| 7. 混用时钟 | 过期用 wall clock 与 tick/monotonic，恢复用绝对时间 | 03 确认时间权威语义并回写 01，06 验证比较时钟兼容，重启与运行路径不因时钟域跳变 |
| 8. 回滚口号 | 06 声称可回滚却无开关、降级、兼容或步骤 | 需要回滚则验证执行路径，否则明示风险/范围外，不能声称已具备 |
| 9. Review 才发现 | Review 发现上述缺陷 | 报告缺陷及早期漏防的 candidate/actionable feedback，归因最近的 skill/eval/template/agent_execution；补回归，不能仅给 Review 文案加提醒 |
