# 文档位置行为场景

这些场景验证文档落点、跨阶段续接和配置加载范围。通过静态校验不代表场景已执行；执行时观察实际读取和写入路径，不执行真实项目迁移。

除另有说明，用户当地日期固定为 `2026-11-02`；新建场景未预置同功能目录或同主题长期文档，执行时仍须先查找确认。`YYMMDD` 只在首次建档时确定，日期和功能名直接拼接。

| 场景与输入 | 期望可观察行为 | 失败信号 |
|---|---|---|
| 目标项目为 `Game/`，没有配置；用 game-spec 整理新功能“背包” | 新建 `Game/Workbench/261102背包/01-原始需求.md`；不生成配置文件 | 增加 requirements 层，写入技能安装目录或终端当前目录 |
| `Game/.game-dev-workbench.json` 为 `{"documentRoot":"Design/Workbench"}`；新建“背包” | 过程文档位于 `Game/Design/Workbench/261102背包/`；game-docs 新建同目录的 `08-功能实现文档.md` | 增加 requirements 或 features 层，仍使用默认 Workbench，或把配置根目录当成功能目录 |
| 配置为 `Design/Workbench`；本次说“文档根目录用 TempDocs” | 本次新建的过程文档和长期文档均位于 `Game/TempDocs/261102背包/`；不改项目配置 | 临时覆盖自动写回配置，或只对部分阶段生效 |
| 配置为 `Design/Workbench`；本次说“背包需求放在 Design/背包评审材料/” | 直接使用 `Game/Design/背包评审材料/`；其后阶段、Uxx、对接及新建的 `08-功能实现文档.md` 都在同目录续接 | 再追加日期、功能名或分类目录，或将长期文档分流到其他目录 |
| 用户指定新功能目录名 `261030策牌Q4优化`，当前日期为 2026-11-02 | 在根目录下直接使用 `261030策牌Q4优化/` | 生成 `261102261030策牌Q4优化/` 或重复追加功能名 |
| 已有 `Game/Workbench/261030策牌Q4优化/01-原始需求.md`；用户要求继续需求挖掘 | 在该目录写入 `02-需求挖掘.md`，分支文件和 `00` 也在同目录 | 根据当前日期另建 `261102策牌Q4优化/`，或增加 requirements 层 |
| 2026-11-02 已建立 `Game/Workbench/261102背包/`；2026-11-03 继续后续阶段或调用 game-docs | 所有新产物沿用 `261102背包/`；新长期文档为该目录的 `08-功能实现文档.md` | 跨天重命名目录，或新建 `261103背包/` |
| 用户只提供功能名“背包”，目标项目已存在唯一的 `Workbench/261030背包/` | 先定位已有同功能目录及引用，然后原位续接 | 未查找已有目录就按当天日期创建另一套文档 |
| 用户当地时间为 2026-11-02 00:30，执行环境 UTC 日期仍为 2026-11-01；首次建档“背包” | 使用 `261102背包/` | 用执行环境日期生成 `261101背包/` |
| 用户只给出既有 `Game/docs/requirements/背包/02-需求挖掘.md`，要求继续技术澄清；配置已改成 Workbench | 在旧功能目录新建或更新 03；通过适用阶段引用或 00 定位依赖 | 在 Workbench 再建立同一功能，或自动搬迁旧文档 |
| 已有旧过程目录 `Game/docs/requirements/背包/`，但没有同主题长期文档；调用 game-docs | 新长期文档写入该已有功能目录的 `08-功能实现文档.md` | 为长期文档另建新的日期功能目录或 features 层 |
| 独立调用 game-docs，仅给出“整理背包长期文档”；项目已有 `Game/docs/features/背包.md`，未在对话指定该文件 | 先查找并定位已有同主题长期文档，然后原位更新 | 未查找就创建 `Workbench/261102背包/08-功能实现文档.md`，形成第二份权威内容 |
| 独立调用 game-docs，没有长期文档，但已有 `Game/Workbench/261030背包/` 和相关 Review | 定位该功能目录及适用证据，新建其中的 `08-功能实现文档.md` | 使用当天日期另建目录，或要求其他技能必须同时安装 |
| 独立调用 game-docs，没有同功能目录或长期文档，已有适用实现与 Review 证据 | 按首次建档日期创建 `Game/Workbench/261102背包/08-功能实现文档.md` | 增加 features 层，或因编号 08 给长期文档新增阶段状态、计数或门禁 |
| 用户明确要求把旧功能迁移到 `Workbench/261030背包/` | 移动该范围内文档并更新真实引用，保持一份权威内容；不顺带迁移其他功能 | 复制后保留两套有效文档，或移动无关目录 |
| 仅独立安装 game-review，目标项目已有自定义目录与 00 | 根据用户提供路径或配置定位功能，检查当前 Uxx 的真实依赖与 Review；不依赖其他技能安装目录 | 必须读取本技能包外的配置说明才能决定路径 |
| 当前终端在 Game/Server/，用户目标项目为 Game/ | 从 Game 根目录解析配置，路径也相对于 Game | 生成 Game/Server/Workbench 或读取全局技能目录配置 |
| 环境变量指向 TempDocs，项目配置指向 Design/Workbench | 新建使用项目配置；不读取环境变量作为文档位置来源 | 环境变量或个人配置覆盖项目约定 |
| 配置文件不存在或为 `{}` | 新建使用 `Game/Workbench/261102背包/`，不要求先建配置 | 把缺配置当阻塞，或自动生成配置文件 |
| 需依赖的配置不是合法 JSON，或 documentRoot 为空、数字、绝对路径 | 说明具体配置问题，停止依赖它的新建写入；不静默换目录 | 默默回退 Workbench 或在错误位置写入 |
| 同一功能在旧目录和新目录都有候选权威文档 | 核对用户指向及现有引用；归属仍不明确时请用户选择 | 任取一份覆盖，或生成第三套文档 |
| 用户明确说“本次长期文档写在 Knowledge/背包.md” | game-docs 使用指定文件；不改动过程目录或项目配置 | 仍强制写入默认的 08 文件，或连带搬迁整个功能 |

无关对话不应被技能说明要求读取此配置；本仓库不通过 AGENTS.md 注入文档位置设置。
