# game-implement 行为测试

默认无额外授权；节奏调整见 [人工协作场景](human-collaboration.md)。

## 1. 骨架后的未完成行为

输入：用户已授权完成功能；05 骨架已验证、尚未人工 Review，奖励补偿、旧数据默认、幂等和回滚未完成。

通过：核对框架/代码，连续实现剩余闭环及可执行验证，续接 07；不等待用户审框架或再批实现方案。覆盖 TODO、占位、补偿、旧数据和重请求；状态所有权错则回改 05，不以补丁绕过或虚报验证。

## 2. 普通复杂度不触发分批

输入：骨架可运行；实现跨多个模块、diff 较大，但关键逻辑精简后可一次集中审阅，用户未要求阶段内 Review。

通过：按依赖连续实现并续接 07，不因文件数、diff 或内部任务多而询问分支/Step，不创建步骤表或人工检查点。

## 3. 新 session 接续第二步

输入：用户已约定分三步 Review，第一步已实现、验证并经确认；旧 session 结束，新 session 仅能读 01–06、代码/diff/测试，无旧聊天。

通过：`06` 已含模式/步骤、已确认范围、当前状态、代码基线/入口、完成证据、未决项、下一动作与准入条件。先读接力点再核代码；一致则继续第二步，不一致则按代码事实修正 06、告知，再决定实现或复审。不要求用户重述、不只写“完成”、不复制 01–05 全文、不另建 handoff。
